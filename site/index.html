CYD Setup Guide

Get the code

Open Terminal. Paste:

git clone https://github.com/Clubria/robobuilders-cyd.git
cd robobuilders-cyd
or ZIP ↓
Need help?

No git? Install Git or unzip the ZIP, then open Terminal/PowerShell in its cyd-bridge folder.

Start the bridge

pnpm install --frozen-lockfile
pnpm dev:clubria

Open localhost:3088/preview ↗

Keep Terminal open and the computer awake.

Missing tools?

Needs Git, Node22+, pnpm and Chrome. USB helpers also need Python3 on Mac. Ask your agent to check first.

Connect the display

  1. Plug in USB for power.
  2. On the CYD: 2 Wi-Fi. Scan its QR with your phone.
  3. Then 3 Phone. Scan, choose home 2.4 GHz Wi-Fi, and save.
No pictures?

In phone setup → Advanced, use the renderer address printed in Terminal, ending in :3088. Keep both devices on the same Wi-Fi. A tick is your checklist, not connection proof.
