# Build an AI Builders CYD app

Open `index.html` in your browser. It is a tiny responsive starter, not a framework.

Ask your AI coding agent:

> Turn this starter into my buildathon idea: [describe it]. Prioritize the240×320 CYD
> screen, while keeping a browser preview usable on my phone/computer. Use touch
> buttons at least44px high. Keep the app preview
> ratio15:4. Do not assume microphone/camera access or send data without explaining
> it. Help me host it on HTTPS, then update app.json with the real URL and requirements.

To share it, use **Add your app** on the App Explorer, or open a pull request adding
the completed `app.json` entry to `site/apps.json` in
https://github.com/Clubria/robobuilders-cyd . Never submit passwords or private keys.

ESP32 displays need the separate streaming bridge; a working browser app is not
automatically native ESP32 firmware. Keep any display-only layout opt-in so it
does not replace the normal desktop/mobile UI.
